# Provenance policy

`openv2b` is an original work. This document records the rules the project follows so that its
open-source status is defensible, and so contributors know where the lines are.

## What this codebase is built from

1. **Published, non-proprietary domain knowledge**: EV battery charge/discharge physics, charger
   power limits, time-of-use tariffs, demand charges, demand-response programs, and classical
   real-time scheduling algorithms (Earliest-Deadline-First, Least-Laxity-First). These are ideas
   and mathematics; they are not copyrightable expression.
2. **A written behavioral specification** (`docs/SPEC.md`) describing *what* a V2B simulator must
   compute: entities, units, dynamics equations, billing arithmetic, and invariants. All code in
   this repository is written against that spec.
3. **Open-source references with compatible licenses**, used as *interface inspiration* only and
   credited where relevant (e.g. [ACN-Sim / acnportal](https://github.com/zach401/acnportal),
   BSD-3-Clause). No code has been vendored from them to date; if that changes, the original
   license header and attribution will be preserved.

## What this codebase must never contain

- Source code, comments, or docstrings copied or paraphrased line-by-line from any proprietary
  simulator or private research codebase.
- Proprietary datasets, trained model weights, or output files generated by proprietary software,
  committed as fixtures. Test fixtures must be synthetic, hand-constructed, or derived from openly
  licensed data (e.g. ACN-Data, under its own terms).
- Dependencies on closed-source solvers in the default build. Optimization backends belong behind
  cargo features, and at least one fully open backend (e.g. HiGHS, MIT-licensed) must remain the
  default for any optimization feature.

## Why "same behavior" is not "a copy"

Copyright protects the *expression* of a program (its code, structure as written, comments), not
the *ideas* it implements (an event loop, an SoC update rule, a demand-charge formula). A simulator
that produces physically equivalent results because it implements the same published physics is an
independent work, provided its code was written independently. This project keeps that provenance
demonstrable by:

- a public, from-scratch git history,
- Developer Certificate of Origin sign-offs on every commit,
- this policy plus `docs/SPEC.md` as the record of what the implementation was written from,
- a test suite derived from first principles (conservation laws, tariff arithmetic worked by hand),
  not from another tool's output files.

## Validation against other simulators

Cross-validating *numbers* against other simulators (open or closed) is normal scientific practice
and does not create a derivative work. Such comparisons live in `docs/VALIDATION.md` as reported
figures; the other tools' inputs/outputs are not committed unless their license allows it.
